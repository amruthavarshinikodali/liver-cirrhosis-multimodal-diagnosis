MULTI MODEL LEARNING FOR LIVER CIRRHOSIS DIAGNOSIS
This project is focused on improving the diagnosis of liver cirrhosis using a multimodal deep learning approach. In real-world healthcare settings, doctors typically consider more than one source of information when making a diagnosis — such as medical imaging and lab reports. Inspired by that, this project combines two types of data: liver scan images and structured clinical records. A CNN (Convolutional Neural Network) is used to process the image data, identifying patterns and abnormalities in the scans, while an LSTM (Long Short-Term Memory) network handles the patient’s structured data like age, test results, and symptoms. The fusion model then brings both sources together, allowing the system to learn more deeply and make predictions based on a complete view of the patient’s condition.
The project is built using Python and implemented through Colab notebooks, making it simple to understand and experiment with. It relies on powerful deep learning libraries such as TensorFlow and Keras for building and training the models. Data processing and analysis are handled using tools like NumPy, Pandas, and Matplotlib. Image data is preprocessed using OpenCV and Keras utilities, while the clinical data undergoes cleaning, normalization, and encoding before being fed into the LSTM. The entire setup runs smoothly on Google Colab, so users don’t need to worry about installing heavy packages locally — everything can be run in the cloud.
In terms of results, each model — CNN and LSTM — performed well on its own, accurately identifying liver cirrhosis based on image or structured data respectively. However, the fusion model that combined both types of input clearly outperformed the individual models. It achieved better accuracy, higher precision, and stronger recall, showing that multimodal learning helps capture a more holistic understanding of the disease. This not only improves the reliability of predictions but also reflects how real-life diagnoses are made — by combining different types of medical evidence. This project demonstrates the potential of AI to assist in more accurate and earlier detection of liver cirrhosis, which could be valuable in clinical decision-making.
